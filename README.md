# VLSI Logic Circuit Analyzer

A Python-based mini EDA tool for analyzing Boolean logic expressions and generating corresponding logic circuit representations.

## 📌 Overview

The VLSI Logic Circuit Analyzer takes a Boolean expression as input and performs basic digital logic analysis. It generates a truth table, estimates logic depth and propagation delay, and automatically visualizes the corresponding gate-level circuit.

The project demonstrates how software-based EDA concepts can be applied to digital logic analysis.

## ✨ Features

- Boolean expression analysis
- Truth table generation
- Input variable detection
- Logic gate counting
- Logic depth estimation
- Propagation delay estimation
- Automatic circuit visualization
- Boolean notation support
- Input validation
- Interactive Streamlit interface

## 🧮 Supported Boolean Notation

The analyzer supports both conventional and standard Boolean notation.
